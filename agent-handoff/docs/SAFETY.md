# 本地安全边界

默认只运行 `mock`。创建任务不会授权外部模型调用。每任务、每服务需要 `authorize --ack-cloud --ack-local-tools`：前者确认工作副本、目标和交接摘要可发送给该服务，后者确认已审查该 CLI 在本机的执行权限、配置、插件和凭据访问行为。已授权路由中的后续 `continue` 无需逐轮确认，受轮次预算约束。

原项目仅用于读取用户明确列出的相对文件路径。控制器不复制整个仓库、不拷贝 `.git`、不运行 Git、不提交、不推送、不修改原项目、不修改现有项目指令。执行区是独立复制目录；同一原项目的不同任务也使用独立副本，合并需人工处理。系统不创建 Git worktree，不支持多个 Agent 同时写同一副本。

路径策略比较保守：隐藏路径、常见凭据路径/扩展名、`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、缓存和依赖目录不会导入。需要这些文件的任务应先整理一个经过审查的干净副本。扫描不能识别所有密钥或保密代码；白名单文件仍须由用户审查。对于多文件/大项目，先拆成边界清晰的小任务。

**隔离副本不是操作系统安全沙箱。** 本控制器和 CLI 运行于当前 macOS 用户身份；恶意或权限过大的 CLI、用户配置、插件、MCP 或可执行脚本仍可能读取副本之外的数据、联网或修改控制目录。协议和提示词不构成硬访问控制。同 UID 的进程可以篡改文件，哈希不是签名。本实现适用于可信用户、可信 CLI 和已审查配置，不用于执行恶意代码。需要硬边界时，应由用户在独立 macOS 账户、VM 或受控 CI 中部署；本包不创建或宣称提供该边界。

控制器只向子进程传入少量环境变量（HOME、PATH、USER、LOGNAME、TMPDIR、LANG，加 NO_COLOR/TERM），不继承 API key 环境变量。CLI 可使用自身已登录凭据；HOME 仍指向用户目录，用户配置中的凭据/插件不是被隔离的。若工具必须通过环境 API key 登录，请使用人工适配，不要把密钥放进任务文件。本包不读取或复制认证文件。

没有 `shell=True`、任意 shell 模板、`--yolo`、`--force`、`--allow-all`、`bypassPermissions`、`--trust`、`--share-gist` 或 `--add-dir`。Codex 使用可写工作区沙箱并忽略用户配置；Claude 使用 bare/dontAsk 和有限文件工具；Antigravity 使用 default 模式和终端 sandbox；Cursor/Copilot 仍依赖用户与组织的实际权限配置。不同工具不是同等的安全沙箱。

每任务 `flock` 确保单写入者，调度器也有全局锁。锁文件必须永久保留；删除它会产生不同 inode 的双重锁。锁描述符传给直接 CLI 子进程，父控制器异常退出时能继续挡住第二个写入者。某些 CLI 会关闭额外描述符或脱离进程组，故恢复仍需人工确认。心跳过期不等于锁可以抢占。手工 GUI Agent 不受 `flock` 约束；`awaiting_manual` 会冻结调度，导入前必须关停 GUI 的本轮任务和后台命令。

超时/中断只终止本次创建的进程组，先 TERM 再 KILL；发现残留则停止接力。恢复不按磁盘里的 PID 杀进程，避免 PID 复用伤及其他程序。锁冲突或进程组仍在时拒绝恢复。即使记录中没有 PGID，操作者也必须确认没有孤儿进程；不会自动续跑异常中断的 `running` 任务。

默认不落盘原始 stdout/stderr，不生成会话全文或上传交接包。只保存通过校验的精简结果和固定错误码；错误原因不会从 stderr 原文写入状态。各厂商 CLI 自己的缓存、遥测和会话历史属于各自行为，本包无法统一禁用或保证清除。Codex 使用 ephemeral，Claude 禁用会话持久化。提示词作为单个 argv 参数传入；同机有足够权限的观察者可能从进程列表看到目标与摘要。

私有状态目录模式 0700，状态/结果/快照普通文件 0600，可执行文件 0700。本地磁盘、Time Machine 和系统备份仍可能保留副本；没有自动清理或加密功能。快照及还原前的备份会持续占用空间。所有快照、备份、结果均保留，删除和归档由用户明确操作。

`export-patch` 只生成新文件，不自动应用；二进制、执行位变化、无末尾换行以及空文件结构变化需人工复制审查。`restore` 只还原工作副本，保留还原前完整副本并转为 paused。不得把这些操作理解为对原项目的回滚。发布、PR、merge、推送和修改工具配置都未实现，也不会隐含发生。
